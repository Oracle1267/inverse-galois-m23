# Zero Spacing Statistics

## Definition

Zero spacing statistics study the gaps, gap ratios, pair correlations, and higher-order correlations among ordinates of nontrivial zeta zeros.

## Attributes

- Type: concept
- Core measurements: normalized gaps, gap ratios, pair correlation, triple correlation, n-level correlation
- Main baseline: random matrix theory and sine-kernel/CUE/GUE predictions

## Relationships

- Part of [[wiki/riemann-hypothesis-investigation-map]].
- Depends on [[entities/concepts/random-matrix-theory]] for baseline comparison.

## Notes

This is the strongest computational path for the current vault, but it is not unexplored. The useful question is whether residual structure remains after known baselines and finite-size corrections.
