# Hardy Z Function

## Definition

The Hardy or Riemann-Siegel `Z(t)` function is a real-valued function on the critical line whose zeros correspond to zeros of zeta on that line.

## Attributes

- Type: concept
- Role: real-valued critical-line observable
- Use: numerical zero finding and sign-change checks

## Relationships

- Supports [[entities/concepts/riemann-hypothesis]] as a computational tool.
- Related to [[entities/concepts/zero-spacing-statistics]] because its zeros provide the ordered sequence of ordinates used in gap studies.
